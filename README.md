# Esercizi EPICODE — Cybersecurity & Ethical Hacking

Repository con le relazioni, i laboratori e i progetti svolti durante il **Master EPICODE in Cybersecurity & Ethical Hacking** (classe CS0226IT).

Ogni cartella corrisponde a una sessione (`S`) e a un laboratorio (`L`) del percorso, con relazioni tecniche in formato PDF/DOCX che documentano obiettivi, procedure, evidenze e conclusioni di ciascuna esercitazione.

---
